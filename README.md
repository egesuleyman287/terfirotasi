# Terfi Rotası

TCDD Taşımacılık A.Ş. görevde yükselme sınavı için hazırlanan mobil uygulamanın ilk çalışan kaynak yapısıdır.

## İlk sürümde bulunanlar

- Dört unvan için başlangıç ekranı
- Ücretsiz ve Premium üyelik durumu
- 10 soruluk örnek sınav akışı
- Sınav sonunda doğru/yanlış ve konu bazlı analiz
- HTML soru dosyası seçip içindeki soru sayısını kontrol eden yönetici ekranı

## Sonraki geliştirmeler

- Gerçek kullanıcı kaydı ve giriş
- Sunucuda kalıcı soru havuzu
- Güvenli HTML soru ayrıştırma ve yayınlama
- Gerçek ödeme sistemi
- Android mağaza paketi ve Google Play yayını

## Çalıştırma

Bilgisayarda Node.js ve Expo kurulumu yapıldıktan sonra proje klasöründe:

```powershell
npm install
npm run android
```

Android telefonda denemek için Expo Go kullanılabilir. Mağazaya yükleme aşamasında bağımsız Android uygulama paketi oluşturulacaktır.
